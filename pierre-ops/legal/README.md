# Legal documents

Client contracts for Pierre Concierge, LLC (DBA Pierre Concierge Nursing), one folder per service under `01 Services`. Start with `00 READ FIRST Attorney Brief.md`.

`_source/build_legal.py` regenerates the agreement, addenda and signing packets (Python, reportlab, pypdf). Edit the text there, rerun, and copy the PDFs into each service folder.

These PDFs are the files to upload to an e-signature tool or attach to a Cal.com workflow email later. Do not use with clients until the LLC is filed and an attorney has reviewed them.
